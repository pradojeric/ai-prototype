# Artifact Origin Research Ledger

Research date: 2026-07-23  
Method: MCP web search and page discovery, prioritizing Philippine government,
tourism, academic, historical, municipal, and established news sources.

Evidence labels:

- **Confirmed** — an official or institutional source directly supports the entry.
- **Supported** — credible sources agree on the association or practice.
- **Tradition** — the living practice is documented, but no precise inventor or
  starting date is established.

## Editorial cautions

- Exact invention dates and named inventors were omitted when reliable sources did
  not establish them.
- Tourism superlatives were avoided unless necessary to explain a documented civic
  identity.
- “Lore” is used for cultural memory and meaning, not supernatural or invented
  history.
- Existing artifact IDs remain stable where display names were corrected, preserving
  saved-game compatibility. Talong Festival's stale `.jpeg` path was corrected to
  the shipped `.png` asset.
